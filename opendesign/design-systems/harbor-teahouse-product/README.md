# 深夜港湾 · 茶歇间产品设计系统

这套系统服务于 DSH 的短时游戏空间：安静、有判断、有陪伴感，但不会变成浮夸的“赌场皮肤”。它把大厅、游戏桌、状态反馈与澜音的陪伴界面统一在同一个夜港叙事里。

## 核心原则

1. **先告诉用户此刻该决定什么。** 分数、风险、轮次和主操作必须在同一视线范围。
2. **让中断是安全的。** 返回大厅、自动存档、任务通知与恢复入口始终可靠。
3. **信息靠层级而不是装饰。** 大画面建立氛围，窄边框和排版组织功能，颜色只负责强调。
4. **短局也要有完整弧线。** 每款游戏都有进入、学习、抉择、反馈、结算和再来一局。

## 组件清单

- 茶歇间壳层：顶栏、任务通知、滚动正文、澜音 Dock
- 大厅：主视觉、编辑期号、精选桌、续玩状态
- 共享游戏层：HUD、比分带、回合状态、主次按钮、错误恢复、加载骨架
- 潮汐拾光：风险尺、航次牌列、收藏连携账本、收帆决策
- 港湾对决：三航线、阵型槽、航标、信号牌、阵型速查
- 鲸牌 Gin Rummy：完整独立主题、规则/设置入口、牌桌与结算

在 `tokens/colors_and_type.css` 中可以直接复用正式 token；`ui-kit-harness/index.html` 是状态总览和视觉回归页。
